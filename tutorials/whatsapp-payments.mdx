---\ntitle: "How to Accept Payments on WhatsApp"\ndescription: "Let customers checkout natively inside WhatsApp."\n---\n\nOTP Edge integrates with UPI, Razorpay, and native WhatsApp Pay. You can send an interactive message with a **Pay Now** button. The user clicks it, completes the transaction securely within the app, and OTP Edge sends a webhook to your server confirming the payment.\n

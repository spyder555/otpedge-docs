---\ntitle: "WhatsApp Co-existence Explained"\ndescription: "Using the App and API on the same number."\n---\n\nMeta now supports co-existence in specific scenarios, but generally, a number on the API cannot be used on the standard WhatsApp mobile app. If you migrate a number from the App to the API, your chat history on the app will be permanently lost. Use a fresh number for OTP Edge if you want to keep your personal app.\n

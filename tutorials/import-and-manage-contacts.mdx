---\ntitle: "How to Import and Manage Contacts"\ndescription: "Learn how to import CSV lists and manage your WhatsApp opt-ins."\n---\n\nTo run successful campaigns on OTP Edge, you need an audience. You can import contacts via a CSV file in the Dashboard under **Audience > Import**. Ensure your CSV has headers for `Phone` (in E.164 format) and any custom attributes like `First Name`. Remember to only import contacts who have explicitly opted in!\n

---\ntitle: "How to Prevent Being Marked as Spam"\ndescription: "Best practices to avoid user reports and account bans."\n---\n\n1. **Always get Opt-in:** Never buy lists.
2. **Clear Opt-out:** Include an opt-out button in your templates.
3. **Relevance:** Send highly targeted, personalized messages instead of generic blasts.
4. **Frequency Cap:** Don't message the same user every day.\n
